# Repository Instructions

- Never run Ruby commands in this repository, including `ruby`, `bundle`, `bundler`, `gem`, `rake`, or `jekyll`.
- Never compile, build, or serve the website, whether through Ruby tooling or any wrapper script, package script, container, or CI command.
- Do not install or update Ruby, gems, Bundler, Jekyll, or the website's build dependencies.
- Make static source changes only.
- When verification is needed, limit it to static inspection of the changed files and clearly state that the website was not compiled.
